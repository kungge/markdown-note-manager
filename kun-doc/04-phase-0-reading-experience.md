# 阶段 0：阅读体验增强

## 1. 目标

在不改变“只读验证版”边界的前提下，减少文章页顶部空间占用，并补齐技术文档阅读中常用的定位、检索、分享和夜间阅读能力。

## 2. 已实现功能

### 2.1 紧凑文章头部

- 路径与标题合并为固定高度的紧凑头部。
- 更新时间、文件大小、标题数量和标签默认收起，通过右侧展开按钮查看。
- 常用操作保留在右上角，正文获得更大的可视区域。

### 2.2 文章大纲与标题层级

- 桌面宽度下，右侧显示二至四级标题大纲。
- 大纲随正文滚动高亮当前章节，点击后平滑定位。
- 一级、二级、三级标题使用明显不同的字号、字重、间距与装饰，便于扫读。
- 窄屏下自动隐藏大纲，为正文让出空间。

### 2.3 文内检索

- 点击“文内查找”或按 `Ctrl+F` / `Cmd+F` 打开当前文章检索。
- 显示当前命中序号和总数，可通过按钮、`Enter`、`Shift+Enter` 在命中项之间移动。
- `Esc` 关闭检索。
- 使用浏览器 Highlight API 绘制高亮，不修改 Markdown 渲染后的 DOM。

### 2.4 阅读进度与快速返回

- 页面顶部使用细进度条显示当前阅读进度。
- 阅读超过一定距离后，右下方显示“返回顶部”按钮。

### 2.5 Markdown 源码

- “查看源码”在渲染视图和原始 Markdown 之间切换。
- 源码视图保留换行和等宽字体，并提供一键复制源码。

### 2.6 分享链接与章节锚点

- “复制链接”生成当前文章的可分享链接。
- 标题悬停时显示链接按钮，点击即可复制当前章节链接。
- 右侧大纲点击后也会更新地址栏锚点。
- 文章链接格式：`/?path=<URL 编码后的笔记路径>`。
- 章节链接格式：`/?path=<URL 编码后的笔记路径>#<标题 slug>`。
- 直接打开或刷新章节链接，会自动打开目标文章并滚动到对应章节。

### 2.7 暗色模式

- 顶部提供浅色/暗色模式切换。
- 选择保存在浏览器本地，刷新页面后继续生效。
- 正文、代码块、表格、大纲、搜索高亮和源码视图均包含暗色样式。

## 3. 验证结果

- TypeScript 类型检查通过。
- Web 与 Server 单元测试通过，共 10 项测试。
- 生产构建通过。
- 浏览器人工验证通过：长文目录、文内检索及命中切换、阅读进度、返回顶部、源码视图、复制文章链接、暗色模式、章节锚点复制、刷新后章节直达。

## 4. 当前边界

- 仍为只读版本，不修改笔记文件。
- 大纲显示二至四级标题；五、六级标题保留在正文中，但不进入悬浮大纲。
- 文内检索单篇文章最多高亮 1000 处，避免极端长文造成明显性能下降。
- 分享链接依赖接收方能访问同一个 NoteHub 本地服务或后续部署的局域网地址；当前不包含公网分享能力。

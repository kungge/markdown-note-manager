# 阶段 0：离线导出

## 1. 目标

允许将当前笔记导出为可以发送给他人、脱离 NoteHub 服务查看的 HTML 或 PDF 文件，同时尽可能保留技术文档常见的标题目录、代码块、表格、图片和 Mermaid 图表。

## 2. 使用方式

文章阅读视图右上角增加“导出”菜单：

- **独立网页（HTML）**：浏览器直接下载单个 `.html` 文件，接收方双击即可打开。
- **打印为 PDF**：打开干净的打印页面并调起浏览器打印窗口；选择“存储为 PDF”或“Microsoft Print to PDF”即可生成文件。

源码视图下导出按钮暂时禁用，切回阅读视图后即可使用。

## 3. 导出内容

- 当前文章渲染后的正文。
- 二至四级标题目录及章节锚点。
- 标题层级、正文、引用、列表、表格和代码块样式。
- 已渲染的 Mermaid SVG。
- 本地图片与远程图片的数据内嵌。
- 笔记原始路径和导出时间。
- 当前浅色或暗色主题；PDF 打印时统一使用适合纸张的浅色配色。

HTML 文件不包含 NoteHub 的侧栏、顶部工具栏、搜索框和操作按钮。

## 4. 图片离线策略

### 本地图片

通过现有工作区附件接口读取，并转换成 Data URL 写入 HTML，因此离开 NoteHub 服务后仍可显示。

### 远程图片

浏览器通过本地服务读取并内嵌远程图片。服务只允许代理当前笔记正文中已经引用的 HTTP/HTTPS 图片，拒绝任意 URL，并执行以下限制：

- 仅接受已支持的图片 MIME 类型。
- 单张图片最大 25 MB。
- 请求超时 12 秒。
- 不缓存远程图片。

如果个别图片下载失败，导出仍会完成，但界面会提示未成功内嵌的图片数量；这些图片在离线环境中可能不可见。

## 5. PDF 实现说明

PDF 使用 Chromium、Chrome、Edge 或 Safari 的原生打印引擎生成，避免额外 PDF 库在中文字体、复杂表格和 SVG 上出现兼容问题。

由于浏览器安全限制，网页不能绕过打印窗口直接写入本地 PDF 文件。用户需要在打印窗口中选择 PDF 目标并确认保存位置。桌面客户端阶段可以再通过原生打印 API 将这一步收敛为直接保存。

## 6. 验证范围

- Windows/macOS 兼容文件名清理。
- HTML 元数据转义，避免标题或路径破坏文档结构。
- 目录与章节锚点生成。
- 远程图片仅限当前文档已引用 URL。
- 图片类型、大小和超时限制。
- 导出菜单、HTML 下载反馈及暗色界面显示。
- TypeScript 类型检查、单元测试和生产构建。
